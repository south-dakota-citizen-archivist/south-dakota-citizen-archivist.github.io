About

South Dakota Citizen Archivist gathers public records about South Dakota and its places from the state and local agencies that publish them, checks them, and keeps them with the documents they come from.

Where the data comes from

Every figure here comes from a public report or file an agency publishes. Each page says which agency and which reports, and each row of its data links to the report it was read from. A copy of every report is kept as well, so a figure can still be checked against its source if the agency's link changes or the report is taken down.

How it's checked

Reports are read by programs written for each one, and checked before they're used: totals have to add up, every county has to be there, and a report's layout has to be one the program knows. A report that fails a check isn't published until it's been looked at. Where an agency's report has a mistake, the page says so and what was done about it; the report itself is kept as published.

Updates

Sources are checked for new reports daily. Each page says when its latest report is from, and _health.json says when the site was last built.

The code and the data

The programs that collect, check and publish the data are open source, and every table can be downloaded from its page. To report a problem or a mistake, open an issue.
